# ASA — подбор event-подрядчиков

Локальный MVP для задачи HackAlem: подбирает до трёх свободных подрядчиков из CSV-каталога и объясняет рекомендации проверяемыми фактами. Бронирований и заявок нет.

## Запуск

Нужен Python 3.10 или новее. Зависимости устанавливать не нужно.

```powershell
python app.py
```

Откройте <http://127.0.0.1:8000>. Остановить сервер: `Ctrl+C`.

## Как устроено

- `data/providers.csv` — исходный анонимизированный каталог (66 профилей).
- `matching.py` — загрузка и нормализация каталога, фильтрация, детерминированное ранжирование и причины.
- `app.py` — HTTP API на стандартной библиотеке Python.
- `index.html` — форма поиска и карточки рекомендаций.

На старте CSV читается в память. Многозначные поля разбираются по `|`, даты занятости превращаются в множество, цена/длительность — в числа, флаги качества — в bool.

## Правила подбора

Город и категория сначала определяют наличие каталожных кандидатов. Затем подрядчик исключается, если он занят в выбранную дату, цена «от» не укладывается в бюджет или он не работает в выбранном формате. Указанная длительность также исключает кандидата, если она выше `max_hours`; пустой `max_hours` считается отсутствием ограничения. Язык опционален и влияет только на ранжирование.

Прошедшие фильтры получают балл: `70 + до 15` за запас бюджета, `+5` за совпадение необязательного языка и `+5` за подтверждённую допустимую длительность. Сортировка: балл по убыванию, затем `id` по возрастанию; показываются первые три. При объяснении перечисляются фактические совпадения, а синтетические и заполненные при подготовке данных поля помечены в карточке.

API `POST /api/recommend` принимает JSON:

```json
{
  "city": "Алматы",
  "date": "2026-10-17",
  "event_format": "свадьба",
  "category": "Фотограф",
  "budget_kzt": 500000,
  "duration_hours": 5,
  "language": "русский"
}
```

`duration_hours` и `language` можно опустить или передать пустыми. `GET /api/options` возвращает значения для формы. Результат имеет `status`: `matched`, `no_category` или `no_matches`, текстовое `message`, список `results` и счётчики причин отказа. Повтор одинакового запроса возвращает тот же порядок.

## Демонстрация

Покажите три исхода:

1. **Плотная категория:** выберите Алматы, категорию «Ведущий» или «Фотограф», осеннюю дату и реалистичный бюджет. Сравните выдачу для двух дат с теми же параметрами: занятые профили должны пропасть, сообщение/состав результатов изменится.
2. **Редкая категория:** выберите «Флорист» или «Декоратор» и параметры, проходящие по цене/формату. Карточки показывают цену, формат и отметки происхождения полей.
3. **Пустая выдача:** задайте существующую категорию и бюджет `0` либо выберите дату, на которую доступные профили заняты. Система объяснит, что кандидаты есть, но они не прошли условия. Для исхода «категории нет в городе» выберите редкую категорию в городе без таких профилей.

Календарь в датасете охватывает 23.09.2026–31.12.2026. Форма ограничивает дату этим диапазоном.

## Ограничения MVP

Выдача опирается на структурированные поля и не использует генеративную модель: так причины остаются воспроизводимыми и проверяемыми. Свободное описание профиля показано на карточке как контекст, но семантическая релевантность по нему пока не оценивается. Цена «от» — нижняя граница из каталога, не финальная смета.
