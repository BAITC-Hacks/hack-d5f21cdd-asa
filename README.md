# ASA — умный подбор event-подрядчиков

![Python](https://img.shields.io/badge/Python-3.10%2B-3776AB?logo=python&logoColor=white)
![Streamlit](https://img.shields.io/badge/UI-Streamlit-FF4B4B?logo=streamlit&logoColor=white)
![Tests](https://img.shields.io/badge/tests-passing-2EA44F)
![HackAlem](https://img.shields.io/badge/HackAlem-%2379--lite-6F42C1)

Пользователь задаёт город, дату, формат мероприятия, категорию и бюджет. Сервис проверяет условия, выбирает до трёх подрядчиков и показывает плюсы и ограничения каждого варианта. Занятые на дату, дороже бюджета и не работающие с выбранным форматом в выдачу не попадают.

## Запуск

Нужен Python 3.10 или новее. В терминале из папки проекта:

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Откройте http://localhost:8501. Если Windows сообщает, что команда `python` не найдена, попробуйте `py -m streamlit run app.py` или запустите через полный путь к `python.exe`.

Другие команды:

```powershell
python demo.py
python -m unittest
```

## Как работает подбор

```text
запрос → matching.py: фильтры, ранжирование, подтверждённые факты
       → comparison.py: плюсы и ограничения между кандидатами
       → explanations.py: короткое объяснение из тех же фактов
       → app.py: интерфейс
```

Сначала формируется пул по городу и категории. Затем применяются жёсткие фильтры: занятость на дату, цена «от» не выше бюджета, подходящий формат и (если указана) длительность. Прошедшие кандидаты получают баллы; при равенстве порядок определяется по `id`.

| Компонент рейтинга | Баллы | Основание |
|---|:---:|---|
| Основное направление | 0–10 | Позиция формата в профиле подрядчика |
| Описание | 0–10 | Упоминания подходящего типа событий |
| Язык | 0–5 | Совпадение с выбранным языком |
| Длительность | 0–5 | Подтверждённый лимит часов |

Цена влияет только на прохождение бюджета и не добавляет баллы.

Для каждого результата сравнение показывает подтверждённые данные: например, самую низкую цену среди выбранных вариантов, отличия по языку или длительности, а также ограничения профиля. Если задан `OPENAI_API_KEY`, ИИ помогает выбрать, какие из уже подготовленных фактов выделить. Он не меняет состав и порядок выдачи. При ошибке API используются локальные правила.

Итоговое объяснение собирается из подтверждённых фактов: формата, свободной даты, бюджета, отличий и при наличии выдержки из профиля. Если профиль синтетический или цена/город добавлены при подготовке каталога, это отдельно отмечается.

## Статусы и подсказки

| Статус | Значение |
|---|---|
| `matched` | Есть подходящие подрядчики |
| `no_match` | Категория найдена, но кандидаты не прошли все условия |
| `category_not_found` | В выбранном городе нет такой категории |

Если вариантов мало, сервис подсказывает, что можно изменить: например, дату, формат или бюджет. Подрядчик указывается для одного конкретного условия, если остальные условия он проходит.

## Демо-сценарии

Сценарии проверены на каталоге в `demo_scenarios.py` и доступны в форме «Быстрый сценарий». Их также можно открыть ссылкой: `http://localhost:8501/?scenario=2`. Добавьте `&debug=1`, чтобы включить подробности подбора.

| № | Пример | Что показывает |
|:---:|---|---|
| 1 | Ведущий · Алматы · свадьба · 15.10 · 1 000 000 ₸ | Сравнение кандидатов с разными сильными сторонами |
| 2 | Тот же запрос на 19.12 | Занятость меняет число результатов |
| 3 | Фотограф · корпоратив · 15.10 · 600 000 ₸ | Сравнение цены и длительности |
| 4–6 | Площадки и флористы | Синтетический профиль и редкая категория |
| 7–8 | Занятые площадки и неподходящий формат | `no_match` и подсказки |
| 9 | Лайв-бэнд · Астана | `category_not_found` |

Для показа жюри: 1 → 2 → 5 → 7 → 9 → 1 со включённой имитацией сбоя ИИ. При сбое выдача сохраняется и сравнение переходит на локальные правила.

## Подключение ИИ

Без ключа проект работает с локальным сравнением. Для включения ИИ задайте переменную окружения `OPENAI_API_KEY`; модель настраивается через `OPENAI_MODEL` (по умолчанию `gpt-4o-mini`). Ключ не нужно вставлять в код или коммитить в репозиторий.

```powershell
$env:OPENAI_API_KEY = "ваш_ключ"
python -m streamlit run app.py
```

В основном потоке `service.run()` отправляет не более одного запроса на сравнение всего TOP‑3. Текст объяснения затем собирается локально из подтверждённых фактов. Отдельная функция `explanations.generate_reason()` поддерживает выбор фактов через модель, но UI её не вызывает. При таймауте, ошибке API или некорректном ответе сравнение строится по локальным правилам.

## Структура проекта

```text
app.py                 Streamlit-интерфейс
service.py             единая точка входа run(request)
matching.py            загрузка каталога, фильтры, ранжирование и факты
comparison.py          подтверждённые плюсы и ограничения между TOP‑3
explanations.py        сборка объяснений и безопасный fallback

test.py                модульные тесты
test_integration.py    сквозные проверки
data/providers.csv     каталог подрядчиков
docs/screenshots/      скриншоты для README
```

## Программный интерфейс

`service.run(request)` возвращает словарь со статусом, заголовком, подсказками, счётчиками и до трёх карточек. Пример запроса:

```python
from service import run

response = run({
    "city": "Алматы",
    "date": "2026-10-15",
    "event_format": "корпоратив",
    "category": "Фотограф",
    "budget_kzt": 600_000,
    # Необязательные фильтры:
    "duration_hours": 6,
    "language": "казахский",
})
```

Каждая карточка содержит профиль подрядчика, оценку, подтверждённые факты, `comparison.pros` и `comparison.cons`, а также `reason` и источник объяснения. Для некорректного запроса возвращается `ValueError`.

Сокращённый пример ответа для флориста в Алматы на 18.10.2026 с бюджетом 300 000 ₸:

```json
{
  "status": "matched",
  "headline": "Подходит 1 из 2 подрядчиков категории «Флорист» в городе Алматы на 18 октября.",
  "counts": {"category_candidates": 2, "busy": 1, "over_budget": 0, "format": 0, "duration": 0, "price_missing": 0},
  "results": [{
    "id": "HK-39372",
    "name": "Тони Тони Чоппер",
    "price_from_kzt": 200000,
    "price_imputed": true,
    "reason": "Берёт свадьбы; дата 18 октября 2026 года в календаре свободна; оценочная цена от 200 000 ₸ укладывается в бюджет 300 000 ₸. В описании профиля: «Мы специализируемся на авторском цветочном оформлении и флористике для мероприятий в Алматы».",
    "reason_source": "fallback"
  }]
}
```
